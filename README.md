# Portfolio – Océane Thauvin

Portfolio personnel conçu et développé pour présenter mes projets, mon parcours et mes compétences en UX/UI Design et Développement Front-End.

🔗 Démo : [https://portfolio-ocette.vercel.app/](https://portfolio-ocette.vercel.app/)

## Aperçu

![Aperçu du portfolio](./assets/images/preview.png)

## Fonctionnalités

- Animation de typewriter dans le hero
- Navigation responsive avec menu hamburger
- Scroll reveal des sections
- Mise en évidence automatique du lien de navigation actif
- Animation de mascotte interactive
- Easter egg caché
- Interface responsive mobile / tablette / desktop

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (ES Modules)
- SVG
- Git & GitHub

````bash
# 7. Démarche de conception

Cette section peut vraiment te démarquer.

```md
## Démarche

Ce portfolio a été conçu avec trois objectifs :

- Mettre en avant mes projets de manière claire
- Créer une expérience utilisateur fluide
- Développer une identité visuelle personnelle

L'interface s'inspire d'un univers coloré et ludique tout en conservant une lecture simple et accessible.
````
